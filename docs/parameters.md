# 参数来源审计（0.4.1）

原则：**不引入魔数，除非直接抄生物参数**。分类标签：

- `[生物]` 直接采用生物测量/常数（当前 0 项——见"下一步抄生物"清单）
- `[尺度]` 由时间尺度、单位归一或无量纲化推导
- `[单位]` 记账单位/单位定义（绝对值任意，比例有意义）
- `[经验]` 目前为经验值——附推导/替换计划

## 动力学

| 参数 | 值 | 类别 | 说明 / 计划 |
|---|---|---|---|
| lam | 0.35 | 经验 | 快记忆带，回声 ≈1.5 步。计划：膜/突触电流衰减 τ≈5–20 ms，token 步长即 Δt → λ=e^(−Δt/τ) |
| lam_slow | 0.95 | 经验 | 慢记忆带 ≈20 步；资格迹 λ 复用之（不再新增常数） |
| c_in | 1.0 | 单位 | 输入幅值基准（其余幅值以此为 1 单位） |
| sigma | 0.02 | 经验 | 膜噪声。计划：生物膜电位噪声 ~1% 量级 |

## 局部学习

| 参数 | 值 | 类别 | 说明 / 计划 |
|---|---|---|---|
| eta_r / eta_coinc / eta_i / eta_b | 0.25 / 0.35 / 0.02 / 0.02 | 经验 | 速率平衡按收敛观测数估算。计划：η ≈ 1/(目标收敛观测数) 闭环 |
| e_ema / nov_ema | 0.02 | 尺度 | 观察窗 ≈50 步（与 lam_slow 同尺度族） |
| nov_slow | 0.002 | 尺度 | 慢窗 ≈500 步（骨架速度的 10× 分层） |
| rpe_gain / blame_gain | 4.0 | 经验 | tanh 饱和增益 |

| 参数 | 值 | 类别 | 说明 / 计划 |
|---|---|---|---|
| pool_in | 0.060 | 单位 | 每步收入基准（记账单位） |
| stress_gain | 2.0 | 经验 | 新颖度加成上限 ×3 |
| G0 | 5.0 | 经验 | 初始预算 ≈ 若干维持成本 |

## 生长

| 参数 | 值 | 类别 | 说明 / 计划 |
|---|---|---|---|
| g_syn / g_neuro / g_dend | 0.15 / 0.001 / 0.35 | 经验 | 生产率与分支比例。计划：以"出生对误差的实际贡献"长期闭环 |
| spine_cost / neuro_cost | 0.10 / 1.0 | 单位 | 出生价（相对 G0=5 定义）；数量自限已交给能量均衡 |
| spine_w0 / coinc_w0 / out_init / birth_* | 0.20 / 0.15 / 0.05 / 多 | 经验 | 初始权重与接线。birth_n_in=5 —— 生物扇入数千，我们按容量预算缩放；计划 fan_in ~ ln V 之类推导 |
| w_res / wd / w_clip | 0.001 / 0.010 / 3.0 | 经验 | 修剪与稳态；0.5.0 起统一用 w_res 作为"小量"尺度 |
| crisis | 3.0 | 经验 | ATP 危机线 |

## 容量上界（仅内存分配，不是生长规则）

cap_syn=16384、cap_coinc=65536、cap_int=1024。

## 小结与下一步

- 共 ~45 项：`[生物]` 0 项、`[单位]/[尺度]` 约 12 项、`[经验]` 约 33 项。
- **下一步抄生物（优先级）**：①膜/突触时间常数（λ 族）；②自发发放率（内部神经元唤醒，0.5.0 使用 1% 驱动）；③ATP 消耗速率（m_* 比例校准）；④皮层扇入/扇出重尾统计（接线参数）。
- **经验值替换顺序**：先学习率 η 族（闭环按观测数），再生长率 g 族（按出生贡献），最后初始权重族。
