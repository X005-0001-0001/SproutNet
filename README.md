# SproutNet

**从一个神经元长出来的语言模型** —— 无反向传播、无阈值、能量预算驱动的生长式神经网络（单文件实现）。

SproutNet 是一个"生长即学习"的神经网络实验：网络拓扑完全由局部动力学决定（生长 / 剪除 / ATP 凋亡），
学习信号只来自 token 流本身（下一 token 预测误差调制）。没有反向传播、没有两次前向对比、
没有外部监督注入。目标是让智能来自**自组织出的先验结构**——没有人类连接组，就让它自己长出一个。

## 核心约束（红线）

1. 无反向传播
2. 无两次前向对比
3. 无外部监督注入（答案不作为外部电流/信号，只有 token 流）
4. 无工程外挂（没有"超上限就删"；生长停止必须由动力学/资源机制涌现）
5. 从 1 个神经元起步；内部神经元上限 96（外周感受器 2V 不计入）
6. 无阈值（一切速率过程 `P = 1 - exp(-rate)`）
7. 同一组参数在任意规模 / 语料 / 词表下稳定；**不引入魔数，除非直接抄生物参数**

## 架构（单文件内核）

- **感受器**：每个 token 两个槽位（fast ≈ 1–2 步回声；slow ≈ 20 步回声），共 2V 个
- **内部神经元 ≤96**：异质时间常数、ATP 代谢、资源枯竭即自然凋亡（无人工删除）
- **学习通路**：突触脊（单通道 → token 行）+ 巧合突触（双通道配对特征 × 稀疏扇出）
- **学习规则**：三因子局部规则（pre × post × 误差调制）+ **资格迹**
  `E ← λ·E + (1-λ)·pre·post`，`w += η·E·调制`；λ 直接取慢记忆时间尺度（非新魔数）
- **巩固**：微睡眠重放（缓冲区满 → 批量混洗重放）
- **生长**：误差驱动定向出生（突触 / 配对 / 神经元）；剪除 = 权重冲突；死亡 = ATP 枯竭
- **能量**：G 池收入（∝ 词表规模的有界亚线性因子 × 新颖度）× 支出（受体 / 神经元 / 尖峰 / 生长），
  破产死亡——G 是唯一的全局资源约束

## 当前进展（实测）

- **记忆容量 scaling（延迟回忆探针）**：k=16 时，cap=96 的"大脑" 2.38 nats vs 小脑 5.05 nats（大脑完胜）；
  k=8 两者持平（1.64 vs 2.38），scaling 签名成立
- **文本学习（Q&A 协议，assistant 掩码 + 防泄露划分，V=10000 BPE）**：
  - 基线（500 条）：unigram PPL 1951 / acc 0.049；bigram acc 0.137
  - 0.3.0（1000 条，3 轮 + 续训）：val PPL 2583 → 2193 → 2046 → **1815**（越过 unigram），acc 0.09
  - 0.4.0（500 条，3 轮）：val PPL **2474 → 2085 → 1906**（越过 unigram），acc 0.09；训练窗已达 1006–1500
- **自适应生长**：内部神经元随需求自发生长至 91+（不再卡在 ~63 的旧均衡）；出生 143 / 死亡 52；
  G 18.4 → 5.7 平滑自限、无爆炸（贵在养不在生；数量由能量均衡涌现）；速度 ≈ 130–400 tok/s（CPU）

## 快速开始

依赖：Python 3.13+，`numpy`，`tokenizers`

```bash
# 自检（训一份小分词器并小规模验证）
python SproutNet_elite_0.4.0.py --smoke

# 训练（Q&A 语料；CPU-only 参考协议：500 条）
python SproutNet_elite_0.4.0.py --train corpus.jsonl --epochs 3 --tokens 60000 --records 500
```

语料格式：JSONL，每行一个记录：

```json
{"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}
```

规则：只对 assistant 段计算 loss 与学习（Q&A 掩码）；按内容哈希 %10 切验证集并跨集去重（防泄露）；
检查点跨运行累积（`brain.pt.npz`）。
