# SproutNet

**从一个神经元长出来的语言模型** —— 无反向传播、无阈值、能量预算驱动的生长式神经网络（单文件实现）。

SproutNet 是一个"生长即学习"的神经网络实验：网络拓扑完全由局部动力学决定（生长 / 剪除 / ATP 凋亡），
学习信号只来自 token 流本身（下一 token 预测误差调制）。没有反向传播、没有两次前向对比、
没有外部监督注入。目标是让智能来自**自组织出的先验结构**——没有人类连接组，就让它自己长出一个。

## 核心约束（红线）

1. 无反向传播
2. 无两次前向对比
3. 无外部监督注入（答案不作为外部电流/信号，只有 token 流）
4. 无工程外挂（没有"超上限就删"；生长停止必须由动力学/资源机制涌现）
5. 从 1 个神经元起步；内部神经元上限 96（外周感受器 2V 不计入）
6. 无阈值（一切速率过程 `P = 1 - exp(-rate)`）
7. 同一组参数在任意规模 / 语料 / 词表下稳定；**不引入魔数，除非直接抄生物参数**

## 架构（单文件内核）

- **感受器**：每个 token 两个槽位（fast ≈ 1–2 步回声；slow ≈ 20 步回声），共 2V 个
- **内部神经元 ≤96**：异质时间常数、ATP 代谢、资源枯竭即自然凋亡（无人工删除）
- **学习通路**：突触脊（单通道 → token 行）+ 巧合突触（双通道配对特征 × 稀疏扇出）
- **学习规则**：三因子局部规则（pre × post × 误差调制）+ **资格迹**
  `E ← λ·E + (1-λ)·pre·post`，`w += η·E·调制`；λ 直接取慢记忆时间尺度（非新魔数）
- **巩固**：微睡眠重放（缓冲区满 → 批量混洗重放）
- **生长**：误差驱动定向出生（突触 / 配对 / 神经元）；剪除 = 权重冲突；死亡 = ATP 枯竭
- **能量**：G 池收入（∝ 词表规模的有界亚线性因子 × 新颖度）× 支出（受体 / 神经元 / 尖峰 / 生长），
  破产死亡——G 是唯一的全局资源约束

## 当前进展（实测）

- **记忆容量 scaling（延迟回忆探针）**：k=16 时，cap=96 的"大脑" 2.38 nats vs 小脑 5.05 nats（大脑完胜）；
  k=8 两者持平（1.64 vs 2.38），scaling 签名成立
- **文本学习（Q&A 协议，assistant 掩码 + 防泄露划分，V=10000 BPE）**：
  - 基线（500 条）：unigram PPL 1951 / acc 0.049；bigram acc 0.137
  - 0.3.0（1000 条，3 轮 + 续训）：val PPL 2583 → 2193 → 2046 → **1815**（越过 unigram），acc 0.09
  - 0.4.0（500 条，3 轮 + 续训 2 轮）：val PPL 2474 → 2085 → 1906 → 1649，acc 0.11
  - 0.5.0（500 条，12 轮）：val PPL **2268 → … → 1542 → 1527 → 1517 → 1512.7**，acc 0.11
    ——同协议每轮全面优于 0.4.x（0.4.x 5 轮为 1649）；后期收益递减
  - **数据规模实验（elite 0.6.0，3000 条全量 / 6×数据，同参数）**：3 轮 val PPL 2405 → 2028 → **1868**（acc 0.09）；
    神经元 3 轮长到 114（500 条同期 ~106）——**N\* 对数据规模不敏感**，目前仍由代谢常数主导
    （与"容量不敏感"对照：CAP_INT 96→1024 时 N\* 基本不变）→ 这正是 `economy` 分支要拆掉的问题
  - **主线 0.8.0（毕业维护，3 轮）+ 主线 15 轮续训**：0.8.0 2332 → 1983 → **1826**（与 modular 首跑逐位一致）；
    15 轮主线 **1493.6**（平台）vs modular 15 轮 **1390.1**——维护机制的优势随轮数拉开（3 轮时尚未显现）
  - **economy 0.2.x（贡献收入，分支）**：0.2.0 用对齐惊讶当收入——量纲不匹配（e 对非观测 token ~1e-4），
    神经元大量饿死（ints 2 高流失 97/95，负结果）；0.2.1 改用读出使用率收入（与维护统计同源），
    12 轮收官：**500 条 1458.0（ints 20）vs 3000 条 6× 数据 1500.6（ints 38）——最终平衡点 N\* +90%**，
    "N\* 由数据决定"的强证据；短期 PPL 代价随轮数收敛（r3 差 63 → r7 差 0.6）
  - **主线 0.8.0 12 轮收官 1437.4（acc 0.12）**：比旧主线（0.5.0 线）1512.7 好 75；modular 独立线仍最好 1410.5
  - **配对通路冻结诊断（pairnorm 分支）**：68,580 行配对权重中位 0.152≈出生初值，前向贡献 fp×w≈1e-3——
    trigram 通路形同虚设（这解释了 PPL 恰在 bigram 水平）；根因=乘积激活 an_i×an_j（~0.01）
    比单源 an（~1）小两个数量级；归一化修复后 c_w p99 0.32→2.14；3 轮尺度 -40（收益若存在只在长程，12 轮判决中）
  - **平滑 n-gram 参照线（同划分同验证集）**：bigram **PPL 730.8** / acc 0.137；trigram 985.4 / 0.167；4-gram 1558.1 / 0.173
    ——当前系统（1458/0.12）仍不如平滑 bigram；**达标线：PPL < 730.8**
- **自适应生长**：内部神经元随需求自发生长至 106（不再卡在 ~63 的旧均衡）；死亡大幅减少（120/14）；
  G 平滑自限、无爆炸（贵在养不在生）；速度 ≈ 90–400 tok/s（CPU）
- **拓扑快照（0.5.0 修复后）**：内部神经元 106 个全部有出突触、**103 个有树突输入**（入度中位 12，修复前为 0）；
  树突突触 1501（修复前 21），自环存活 90；token 行枢纽复现（t205/t268/t271…，与 0.4.x 独立运行高度重合，结构可复现）
- **任务特化实验（elite 0.6.0，同一内核/同一参数）**：
  - 代码脑（2.08MB 源码取 1200 块）6 轮：VAL PPL 612 → 474 → 355 → 332 → 306 → **287**（acc 0.16）；
    拓扑稳定：枢纽不变（`_` `.` `(` `=`…）、覆盖 6.9%（集中度高，基尼 0.71）、内部图聚类 19.7× 随机
  - **枢纽 token 完全不同、且各自符合任务语义**：
    问答脑 → `\n` `的` `，` `**`（中文文本骨架）；代码脑 → `_` `.` `(` `=` `,` ` =` `)` `\n       `（Python 语法与缩进骨架）
  - 代码脑度分布更集中（基尼 0.70 vs 0.60、token 行覆盖 5.7% vs 18.7%）——代码关键 token 少而重
  - 内部图聚类：问答 64.6×（22 边）、代码 22.0×（50 边）——各自都显著超随机
- **modular 0.1.0（读出维护对称化，分支实验）**：12 轮 val PPL **1410.5**（acc 0.13）——优于 elite 主线 12 轮的 1512.7，
  而内部神经元仅 **3 个存活**（elite 为 108）：读出衰减清退死突触 → 无功能神经元被淘汰 → 需求来时按需重生（出生/死亡 219/216，动态平衡）；
  同性能下内部层压缩到 ~1/36；acc 0.13 逼近 bigram 基线 0.137
- **拓扑量化（0.5.1，6 轮 / 557k 步）**：
  - token 行入度重尾：p50=1 / p99=42 / max=250，基尼 0.60，尾斜率 α≈0.98
    （受词频 Zipf 影响，比皮层 α≈2–3 更极端；绝对枢纽复现三次）
  - 内部图（int→int，22 边）：聚类 **C=0.150 vs 随机基线 0.002（64.6×）**——小世界式成簇；自环 88、互环 1
  - 内部神经元出度均匀（中位 20，基尼 0.25）、入度集中（中位 5，基尼 0.56）
  - 读出耦合投影 ≈ 随机基线（1.0×）：内部神经元目前弥散投射、尚无输出模块化（诚实的负结果 → 0.6.x 方向）

## 快速开始

依赖：Python 3.13+，`numpy`，`tokenizers`

```bash
# 自检（训一份小分词器并小规模验证）
python SproutNet_elite_0.4.0.py --smoke

# 训练（Q&A 语料；CPU-only 参考协议：500 条）
python SproutNet_elite_0.4.0.py --train corpus.jsonl --epochs 3 --tokens 60000 --records 500
```

语料格式：JSONL，每行一个记录：

```json
{"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}
```

规则：只对 assistant 段计算 loss 与学习（Q&A 掩码）；按内容哈希 %10 切验证集并跨集去重（防泄露）；
检查点跨运行累积（`brain.pt.npz`）。
